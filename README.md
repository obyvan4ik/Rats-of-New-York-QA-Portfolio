# Rats of New York — QA Portfolio

**Manual Software Testing | Test Documentation | Bug Reporting | Front-End Development**

## Project Overview

**Rats of New York** is a fictional, single-page web application developed and tested as part of my personal Software Quality Assurance portfolio.

The purpose of this project is to demonstrate my practical skills in manual software testing, requirements analysis, test case design, test execution, defect reporting, and basic front-end development.

I developed the website using HTML, CSS, and JavaScript and performed manual testing to identify functional, usability, accessibility, and user interface issues.

### Live Website

**[View the Live Website](https://obyvan4ik.github.io/Rats-of-New-York-QA-Portfolio/)**

## Website Features

The application includes:

- Navigation menu and interactive search interface
- Home and Help sections
- Donation options and donation information modal
- Interactive slider with eight fictional rat stories
- Petition form with input fields and signature counter
- Contact information and external links
- Responsive layouts for desktop, tablet, and mobile devices

Some features contain known defects that have been documented in the QA testing process.
