# Rats of New York — QA Portfolio

**Manual Software Testing | Bug Reporting | Front-End Development**

Rats of New York is a fictional, single-page website created as a personal Quality Assurance portfolio project.

The project demonstrates my practical experience in manual software testing, requirements analysis, test design, test execution, defect reporting, and basic front-end development.

## Live Website

[View Rats of New York](https://obyvan4ik.github.io/Rats-of-New-York-QA-Portfolio/)

## Project Overview

The website includes the following features:

- Responsive navigation and search interface
- Donation options and donation information modal
- Interactive slider featuring eight fictional rat stories
- Petition form with input validation and signature counter
- Contact information, resume, and external links

## My Responsibilities

As the developer and manual QA tester, I was responsible for:

- Developing the website using HTML, CSS, and JavaScript
- Analyzing and documenting functional and non-functional requirements
- Creating a Test Plan, Test Scenarios, and Test Cases
- Performing positive, negative, boundary value, and exploratory testing
- Testing responsive layouts and cross-browser compatibility
- Identifying, reproducing, and documenting software defects
- Tracking defects using Jira Software
- Preparing a Requirements Traceability Matrix
- Preparing regression tests and a Test Summary Report
